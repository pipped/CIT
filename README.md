# CIT Labs

Hands-on IT infrastructure, security, and systems labs documenting practical work across virtualization, identity management, penetration testing, and cloud platforms.

## Labs

| Lab | Focus |
|---|---|
| [ESXi Infrastructure Deployment](esxi-lab/) | RAID 10 setup, VMware ESXi installation, management network config, UniFi Dream Machine Pro |
| [Active Directory](active-directory-lab/) | Forest and domain setup, OU structure, users and groups, Group Policy, workstation domain join |
| [Penetration Testing](pentest-lab/) | Recon, Nmap scanning, SMB/FTP/web enumeration, exploitation, post-exploitation, findings report |
| [Apache CloudStack](cloudstack-lab/) | CloudStack management server install, MySQL config, database initialization on Ubuntu |
| [Course Lab Notes](course-labs/) | Network commands, IPv4 subnetting, Remote Desktop, RRAS, and CloudStack pod setup |

## Skills Represented

- Bare-metal server and hypervisor deployment
- RAID configuration and storage management
- Active Directory and Group Policy administration
- Penetration testing methodology and tooling
- Cloud platform installation and configuration
- Network command-line tools and IPv4 fundamentals
- Remote access and VPN concepts
- Infrastructure documentation and troubleshooting
